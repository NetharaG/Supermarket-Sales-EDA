# Supermarket Sales Analysis using EDA

## Project overview
This project demonstrates exploratory data analysis of supermarket transactions using Python.

## Dataset disclosure
`supermarket_sales.csv` is a **simulated educational dataset** generated for this project starter. It is not collected from a real supermarket. It contains transaction, branch, customer, product-line, payment, pricing and rating fields. It includes a small number of missing values and duplicate rows so that data-cleaning steps can be demonstrated.

## Tools
- Python
- Google Colab / Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn

## How to run in Google Colab
1. Open https://colab.research.google.com/
2. Upload `Supermarket_Sales_EDA.ipynb`.
3. Run the notebook cells in order.
4. When prompted, upload `supermarket_sales.csv`.
5. Review the printed statistics, charts and findings.

## Project files
- `supermarket_sales.csv` — dataset
- `Supermarket_Sales_EDA.ipynb` — executable notebook
- `Project_Report.pdf` — project report
- `graphs/` — generated example charts

## Main analysis
1. Data inspection and cleaning
2. Descriptive statistics
3. Revenue by product line and branch
4. Payment-method distribution
5. Transaction-value distribution
6. Quantity versus transaction total
7. Correlation analysis

## Important
Do not describe simulated data as real-world collected data. If your instructor requires a real dataset, replace the CSV with an appropriately licensed public dataset and update the report and findings.
